# Services

Je kunt de data van Oorlogsbronnen op verschillende manieren bevragen. Welke
service past, hangt af van wat je bouwt:

- **[API's](./apis)**: een REST API op basis van Spinque, met een
  JavaScript/TypeScript-client. De gebruikelijke keuze voor websites en
  applicaties.
- **[SPARQL](./sparql)**: het SPARQL-endpoint op LDmax, voor eigen queries op
  de linked data. Geschikt voor onderzoeksvragen en datakoppelingen.
- **[Termennetwerk](./termennetwerk)**: termen uit de WO2 Thesaurus opzoeken
  en gebruiken in je eigen invoervelden.
- **[LLMs](./llms)**: machine-leesbare versies van deze documentatie voor
  AI-agents en LLM-tools.
