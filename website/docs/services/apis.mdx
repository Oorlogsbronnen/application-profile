# API's

De data van Oorlogsbronnen is via een REST API te bevragen, gebouwd op [Spinque](https://www.spinque.com/). De API is publiek en vereist geen API-key.

## Opbouw van een request

Alle endpoints leven onder één basis-URL:

```text
https://rest.spinque.com/4/oorlogsbronnen/api/lod/e/
```

Daarachter volgt het endpoint met zijn parameters volgens het patroon `{endpoint}/p/{parameter}/{waarde}/resultpage`, afgesloten met `?config=default`. Parameterwaarden zijn URL-encoded. Voorbeeld:

```text
…/api/lod/e/person/p/id/{IRI}/resultpage?config=default
```

Handige queryparameters: `count` (aantal resultaten) en `offset` (paginering). De API publiceert ook een machine-leesbare OpenAPI-beschrijving van alle endpoints: [swagger.json](https://rest.spinque.com/4/oorlogsbronnen/api/lod/swagger.json?config=default).

## Zoeken: `search`

Vrij zoeken door alle bronnen, personen en thema's. Als rode draad gebruiken we — net als op de [SPARQL-pagina](./sparql) — verzetsstrijder Hannie Schaft:

<Tabs groupId="taal">
  <TabItem value="curl" label="curl">

```sh
curl "https://rest.spinque.com/4/oorlogsbronnen/api/in10/e/search/p/topic/hannie%20schaft/results?config=production&count=1"
```

  </TabItem>
  <TabItem value="js" label="JavaScript">

```ts
import { Api, Query } from "@spinque/query-api";

const api = new Api({
  workspace: "oorlogsbronnen",
  api: "in10",
  config: "production",
  version: "4",
});

const query: Query = {
  endpoint: "search",
  parameters: { topic: "hannie schaft" },
};

const results = await api.fetch(query);
```

  </TabItem>
  <TabItem value="python" label="Python">

```python
from spinque_query_api import Api, Query

api = Api(workspace="oorlogsbronnen", api="in10", config="production")

query = Query(endpoint="search", parameters=[("topic", "hannie schaft")])
results = api.fetch(query, {"count": 10})
```

</Tabs>

## Eén persoon ophalen: `person`

De lod-API haalt een persoon op met dezelfde ARK-IRI die je in de [linked data](../datasets/linked-data) tegenkomt — API en SPARQL-endpoint verwijzen dus naar hetzelfde ding:

<Tabs groupId="taal">
  <TabItem value="curl" label="curl">

```sh
curl "https://rest.spinque.com/4/oorlogsbronnen/api/lod/e/person/p/id/https%3A%2F%2Fn2t.net%2Fark%3A%2F59857%2Fp48968c01-9f60-492d-8712-58d3b8c2b388/resultpage?config=default"
```

  </TabItem>
  <TabItem value="js" label="JavaScript">

```ts
const iri = "https://n2t.net/ark:/59857/p48968c01-9f60-492d-8712-58d3b8c2b388";
const url =
  "https://rest.spinque.com/4/oorlogsbronnen/api/lod/e/person" +
  `/p/id/${encodeURIComponent(iri)}/resultpage?config=default`;

const response = await fetch(url);
const { items } = await response.json();
```

  </TabItem>
  <TabItem value="python" label="Python">

```python
from urllib.parse import quote
import requests

iri = "https://n2t.net/ark:/59857/p48968c01-9f60-492d-8712-58d3b8c2b388"
url = (
    "https://rest.spinque.com/4/oorlogsbronnen/api/lod/e/person"
    f"/p/id/{quote(iri, safe='')}/resultpage?config=default"
)

items = requests.get(url).json()["items"]
```

## Objecten bij een trefwoord: `keyword_objects`

Alle collectie-objecten die gekoppeld zijn aan een concept uit de [WO2 Thesaurus](https://data.niod.nl/WO2_Thesaurus/), hier het concept [Verzet](https://data.niod.nl/WO2_Thesaurus/2657). Wil je alleen `id`, `title` en `type`, gebruik dan de compacte variant `keyword_object_list`; voor personen bij een trefwoord is er `keyword_persons`.

## Libraries

Spinque biedt officiële client-libraries:

- [`@spinque/query-api`](https://www.npmjs.com/package/@spinque/query-api) (JavaScript/TypeScript): npm-package voor Node ≥ 18 of de browser.
- [`spinque-query-api`](https://pypi.org/project/spinque-query-api/) (Python): `pip install spinque-query-api`; zie de [broncode op GitHub](https://github.com/spinque/query-api-python).

Let op: de libraries bouwen alleen de resultaatvormen `results` en `statistics`. De endpoints van deze API antwoorden op `resultpage` — gebruik daarvoor gewone HTTP-requests, zoals in de voorbeelden hierboven.
