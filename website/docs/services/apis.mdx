# API's

De [linked data-datasets](../datasets/personen-en-objecten) over personen en objecten zijn ook op te vragen via de openbare REST API van Oorlogsbronnen. Elk endpoint is een gewone `GET`-request en geeft JSON-LD terug:

| | |
| --- | --- |
| Basis-URL | `https://data.oorlogsbronnen.nl/services/api` |
| Methode | `GET` |
| API-sleutel | Niet nodig |
| Antwoord | JSON-LD |
| Specificatie | [Swagger UI](https://data.oorlogsbronnen.nl/services/api/docs) · [openapi.json](https://data.oorlogsbronnen.nl/services/api/openapi.json) |

## Personen

### `/persons` {#persons}

Personen zoeken met filters. Minstens één filter is verplicht. Een filter is een URI uit de WO2 Thesaurus of een naam die precies overeenkomt met een `prefLabel`, `altLabel` of `hiddenLabel` van de term, zonder op hoofdletters te letten. Dezelfde filter herhalen betekent OF, verschillende filters combineren betekent EN.

<ApiRequest
  endpoint="/persons"
  query={{
    birthplace: ["https://data.niod.nl/WO2_Thesaurus/locations/9881"],
    deathplace: [],
    keywords: [],
    count: 10,
    offset: 0,
  }}
  jsonOnly
/>

### `/person/p/id/{id}` {#person}

Eén persoon met biografische gegevens, familierelaties en thesaurustermen. In `wasDerivedFrom` staan de persoonsvermeldingen uit de afzonderlijke bronnen, en in elke vermelding in `actor` de gebeurtenissen die die bron noemt. Een uitleg per onderdeel staat in het cookbook [Alles over een persoon](../api-cookbook/persoon.mdx).

<ApiRequest
  endpoint="/person/p/id/{id}"
  pathParams={{ id: "48968c01-9f60-492d-8712-58d3b8c2b388" }}
  query={{}}
  jsonOnly
/>

### `/person_related_objects/{id}` {#person_related_objects}

Historische foto's en objecten uit WO2-collecties die aan één persoon zijn gekoppeld.

<ApiRequest
  endpoint="/person_related_objects/{id}"
  pathParams={{ id: "48968c01-9f60-492d-8712-58d3b8c2b388" }}
  jsonOnly
/>

## Objecten

### `/objects` {#objects}

Objecten zoeken met filters. Minstens één filter is verplicht. Een filter is een URI uit de WO2 Thesaurus of een naam die precies overeenkomt met een `prefLabel`, `altLabel` of `hiddenLabel` van de term, zonder op hoofdletters te letten. Dezelfde filter herhalen betekent OF, verschillende filters combineren betekent EN.

<ApiRequest
  endpoint="/objects"
  query={{
    about: ["https://data.niod.nl/WO2_Thesaurus/2657"],
    publisher: [],
    count: 10,
    offset: 0,
  }}
  jsonOnly
/>

### `/object/{id}` {#object}

Eén object op basis van de URI bij de bron of dataprovider.

<ApiRequest
  endpoint="/object/{id}"
  pathParams={{
    id: "https://www.collectiegelderland.nl/object/0cc74396-2c2e-9316-6023-27a4773e98eb",
  }}
  labels={{ id: "URI van het object bij de bron" }}
  jsonOnly
/>
