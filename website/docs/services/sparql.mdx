# SPARQL

De [linked data-datasets](../datasets) zijn te bevragen via het publieke SPARQL-endpoint van Stichting WO2Net op LDMax:

```text
https://platform.ldmax.nl/organisaties/wo2net/query
```

### Wat kun je hier doen?

De SPARQL IDE is bedoeld voor gerichte datavragen. Je kiest een organisatie met endpoint, schrijft of plakt een query en ziet de resultaten direct in tabel-, kaart- of JSON-vorm. Queries kunnen lokaal worden opgeslagen in de browser.

## Aanpak

Start met het bestuderen van de voorbeeldqueries op deze pagina of begin met een eenvoudige SELECT met LIMIT op [https://platform.ldmax.nl/organisaties/wo2net/query](https://platform.ldmax.nl/organisaties/wo2net/query). Voer de query uit en controleer eerst of de bindings logisch zijn. Verfijn daarna pas met extra joins, filters en aggregaties.

Het is verreweg het beste om je queries direct uit te voeren op [https://platform.ldmax.nl/organisaties/wo2net/query](https://platform.ldmax.nl/organisaties/wo2net/query). Alleen de ARK URI's van personen [resolven](contentnegotiation) ook buiten het LDMax platform naar de knowledge graph.


## Opgeslagen queries

Gebruik binnen LDMax opgeslagen queries voor terugkerende analyses. Zo houd je werkbare queryversies bij en hoef je niet steeds opnieuw te beginnen.

:::tip[Probeer het hieronder direct]

De queryblokken op deze pagina zijn **uitvoerbaar**: pas ze aan en druk op de knop (of `Ctrl` + `Enter`).

:::

## Een persoon zoeken

[Persoonsreconstructies](/schema#PersoonsReconstructieShape) zijn te doorzoeken op naam of andere biografische gegevens. Een combinatie is ook mogelijk.

<SparqlEditor
  query={`PREFIX picom: <https://personsincontext.org/model#>
PREFIX sdo: <https://schema.org/>
SELECT * WHERE {
  ?persoon a picom:PersonReconstruction ;
           sdo:name ?naam .
  OPTIONAL { ?persoon sdo:birthDate ?geboren }
  OPTIONAL { ?persoon sdo:deathDate ?overleden }
  OPTIONAL { ?persoon sdo:deathPlace ?overlijdensplaats }
  FILTER(CONTAINS(LCASE(?overlijdensplaats), "overveen"))
}
ORDER BY ASC(?naam)
LIMIT 10`}
/>


## Bronnen over een persoon zoeken

[Bronnen](/schema#objecten) uit WOII collecties hebben ook vaak betrekking op personen, maar maken niet perse onderdeel uit van de persoonsreconstructie. In dit voorbeeld zoeken we via de relatie `sdo:about` door alle collecties heen naar foto's waarop Anne Frank is afgebeeld:

<SparqlEditor
  query={`PREFIX sdo: <https://schema.org/>
SELECT ?object ?title ?about ?name ?image WHERE {
?object a sdo:Photograph ;
        sdo:name ?title ;
        sdo:about ?about ;
        sdo:thumbnailUrl ?image .
  
?about sdo:name ?name .

FILTER(CONTAINS(LCASE(STR(?name)), "frank"))
}
LIMIT 20`}
/>
