# SPARQL

De [linked data-datasets](../datasets/personen-en-objecten) zijn te bevragen via het publieke SPARQL-endpoint van Stichting WO2Net op LDMax:

```text
https://platform.ldmax.nl/organisaties/wo2net/query
```

### Wat kun je hier doen?

De SPARQL IDE is bedoeld voor gerichte datavragen. Je kiest een organisatie met endpoint, schrijft of plakt een query en ziet de resultaten direct in tabel-, kaart- of JSON-vorm. Queries kunnen lokaal worden opgeslagen in de browser.

## Aanpak

Selecteer eerst het juiste endpoint. Start met een voorbeeldquery of een eenvoudige SELECT met LIMIT. Voer de query uit en controleer eerst of de bindings logisch zijn. Verfijn daarna pas met extra joins, filters en aggregaties.

## Opgeslagen queries

Gebruik opgeslagen queries voor terugkerende analyses. Zo houd je werkbare queryversies bij en hoef je niet steeds opnieuw te beginnen.

:::tip[Probeer het hieronder direct]

De queryblokken op deze pagina zijn **uitvoerbaar**: pas ze aan en druk op de knop (of `Ctrl` + `Enter`).

:::

## Een persoon zoeken

[Persoonsreconstructies](/schema#PersoonsReconstructieShape) zijn te doorzoeken op naam of andere biografische gegevens. Een combinatie is ook mogelijk.

<SparqlEditor
  query={`PREFIX picom: <https://personsincontext.org/model#>
PREFIX sdo: <https://schema.org/>
SELECT * WHERE {
  ?persoon a picom:PersonReconstruction ;
           sdo:name ?naam .
  OPTIONAL { ?persoon sdo:birthDate ?geboren }
  OPTIONAL { ?persoon sdo:deathDate ?overleden }
  OPTIONAL { ?persoon sdo:deathPlace ?overlijdensplaats }
  FILTER(CONTAINS(LCASE(?overlijdensplaats), "overveen"))
}
ORDER BY ASC(?naam)`}
/>

## Van reconstructie naar vermeldingen

Eén van de personen in bovenstaande lijst is Hannie Schaft. De persoonsreconstructie bij Oorlogsbronnen is opgebouwd uit [persoonsvermeldingen](/schema#PersoonsvermeldingShape) uit verschillende bronnen, gekoppeld via `prov:wasDerivedFrom` en `sdo:hadPrimarySource`. Zo zie je in welke bronnen Hannie Schaft voorkomt — en onder welke namen en beroepen:

<SparqlEditor
  query={`PREFIX prov: <http://www.w3.org/ns/prov#>
PREFIX sdo: <https://schema.org/>
SELECT ?vermelding ?naam ?beroep ?dataset ?bron WHERE {
  <https://n2t.net/ark:/59857/p48968c01-9f60-492d-8712-58d3b8c2b388>
      prov:wasDerivedFrom ?vermelding .
  ?vermelding sdo:name ?naam ;
              prov:hadPrimarySource/sdo:isPartOf/sdo:name ?dataset ;
              prov:hadPrimarySource/sdo:holdingArchive/sdo:name  ?bron             .
  OPTIONAL { ?vermelding sdo:hasOccupation ?beroep }
}`}
/>

## Bronnen over een persoon

[Bronnen](/schema#objecten) uit WOII collecties hebben ook vaak betrekking op personen, maar maken niet perse onderdeel uit van de persoonsreconstructie. In dit voorbeeld zoeken we via de relatie `sdo:about` door alle collecties heen naar foto's waarop Anne Frank is afgebeeld:

<SparqlEditor
  query={`PREFIX sdo: <https://schema.org/>
SELECT ?object ?name ?description ?image WHERE {
  ?object a sdo:Photograph ;
          sdo:name ?name ;
          sdo:about ?about ;
          sdo:thumbnailUrl ?image .
  
  OPTIONAL { ?object sdo:description ?description }
  
  FILTER(CONTAINS(LCASE(STR(?about)), "anne frank"))
}`}
/>

## Trefwoorden uit de WO2 Thesaurus

Personen zijn via `sdo:keywords` verbonden met [thesaurusconcepten](/schema#ConceptShape); de Nederlandse labels haal je op met `skos:prefLabel`:

<SparqlEditor
  query={`PREFIX sdo: <https://schema.org/>
PREFIX skos: <http://www.w3.org/2004/02/skos/core#>
SELECT ?concept ?label WHERE {
  <https://n2t.net/ark:/59857/p48968c01-9f60-492d-8712-58d3b8c2b388>
      sdo:keywords ?concept .
  ?concept skos:prefLabel ?label .
  FILTER(LANG(?label) = 'nl')
}`}
/>
