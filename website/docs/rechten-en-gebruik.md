# Rechten en gebruik

De informatie in zowel de dataset WO2 Collecties Oorlogsbronnen als in de dataset WO2 Personen Oorlogsbronnen bestaat uit data aangeleverd door de verschillende deelnemers aan Oorlogsbronnen.nl. De data zijn verrijkt door middel van de WO2-thesaurus. De WO2 Personen Oorlogsbronnen dataset bevat Persoonsreconstructies die door WO2Net zijn gecreëerd op basis van de persoonsvermeldingen die door de deelnemende instellingen zijn aangeleverd.
