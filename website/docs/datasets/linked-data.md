# Linked data (LDmax)

De data van Oorlogsbronnen is als Linked Open Data gepubliceerd op [LDmax](https://platform.ldmax.nl/organisaties/wo2net), onder de organisatie **Stichting WO2Net**.

## Datasets

| Dataset                                                                                | Inhoud                                                                                     | Licentie        |
| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ | --------------- |
| [WO2 Personen Oorlogsbronnen](https://platform.ldmax.nl/datasets/wo2net/personen/)     | Personen betrokken bij WOII in Nederland: getuigen, slachtoffers, militairen en anderen.   | CC-BY-NC-SA 4.0 |
| [WO2 Collecties Oorlogsbronnen](https://platform.ldmax.nl/datasets/wo2net/collecties/) | Metadata van ±180 WOII-gerelateerde collecties: foto's, archieven, video, audio en boeken. | CC-BY-NC-SA 4.0 |

Daarnaast publiceert WO2Net de [WO2 Thesaurus](https://platform.ldmax.nl/datasets/wo2net/thesaurus/) (±17.000 termen, CC0 1.0).

De datasets zijn te bevragen via het [SPARQL-endpoint](../services/sparql).
