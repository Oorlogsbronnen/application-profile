# Zoeken via de thesaurus

**Vraag:** ik heb een onderwerp ("verzet") waarover ik meer informatie wil. Hoe vind ik het juiste concept in de WO2 Thesaurus en vervolgens de personen of objecten die daaraan gekoppeld zijn?

## WO2 Thesaurus URI's vinden

Personen zijn via `sdo:keywords` verbonden met [thesaurusconcepten](/schema#ConceptShape) uit de WO2 Thesaurus, objecten via `sdo:about`. Het kan moeilijk zijn om te bepalen wat het juiste thesaurusconcept is voor de term die je zoekt. Deze query helpt daarbij door te zoeken door alle `skos:prefLabel`, `skos:altLabel` en `skos:hiddenLabel` waardes in de WO2 Thesaurus:

<SparqlEditor
  query={`PREFIX skos: <http://www.w3.org/2004/02/skos/core#>

SELECT DISTINCT ?concept ?label WHERE {
  # ?label matcht zowel skos:prefLabel als skos:altLabel en skos:hiddenLabel
  ?concept (skos:prefLabel | skos:altLabel | skos:hiddenLabel) ?label .
  
  # Gebruik een filter om alleen in de Nederlandstalige labels te zoeken
  FILTER(LANG(?label) = 'nl')
  
  # Hoofdletterongevoelige substring filter. Vervang "verzet" door de term die je zoekt
  FILTER(CONTAINS(LCASE(STR(?label)), "verzet"))
}
LIMIT 50`}
/>

## Vind personen bij het concept

Neem de concept-IRI uit stap 1 en gebruik die als waarde van `sdo:keywords`:

<SparqlEditor
  query={`PREFIX picom: <https://personsincontext.org/model#>
PREFIX sdo: <https://schema.org/>
SELECT ?persoon ?naam WHERE {
  ?persoon a picom:PersonReconstruction ;
           sdo:keywords <https://data.niod.nl/WO2_Thesaurus/2657> ;
           sdo:name ?naam .
}
LIMIT 20`}
/>

## Wat krijg je terug

Stap 1 levert de verzetsgerelateerde concepten uit de thesaurus; stap 2 toont personen die aan zo'n concept gekoppeld zijn. Verken vanaf een concept ook de hiërarchie met `skos:broader` en `skos:narrower` (zie de [ConceptShape](/schema#ConceptShape)).

# Vind bronnen op onderwerp en locatie

Neem de concept-IRI uit stap 1 en gebruik die als waarde van `sdo:about`. De thesaurus bevat ook oorlogsplekken, die als 'sdo:contentLocation' aan bronnen gekoppeld zijn. Onderstaande query combineert beide waardes:

<SparqlEditor
  query={`PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX sdo: <https://schema.org/>

SELECT DISTINCT * WHERE {
  ?object a ?type ;
  # about en contentLocation zijn WO2 Thesaurus ID's
  sdo:about <https://data.niod.nl/WO2_Thesaurus/2860> ;
  sdo:contentLocation <https://data.niod.nl/WO2_Thesaurus/locations/9577> ;
  sdo:name ?name ;
  sdo:thumbnailUrl ?thumbnailUrl.

  # ?type matcht matcht ook alle subclasses van sdo:CreativeWork
  ?type rdfs:subClassOf* sdo:CreativeWork .
}

`}
/>

## Wat krijg je terug

Deze query geeft alle objecten: 
- met als onderwerp de Hongerwinter.
- met als onderwerpslocatie Amsterdam.
- van het type `sdo:CreativeWork` of één van haar subclasses.
- waarbij een afbeelding beschikbaar is.
