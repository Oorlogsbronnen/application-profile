# SPARQL queries met betrekking tot een persoon

## Hoe het model werkt

Een [persoonsreconstructie](/schema#PersoonsReconstructieShape) bij Oorlogsbronnen is opgebouwd uit één of meer [persoonsvermeldingen](/schema#PersoonsvermeldingShape), gekoppeld via (`prov:wasDerivedFrom`). De persoonsvermeldingen zijn afkomstig van een [bron](/schema#SourceShape), gekoppeld via `sdo:hadPrimarySource`.

[Gebeurtenissen](/schema#EventShape) in het leven van een persoon zijn gelinkt aan de **vermeldingen** — niet direct aan de reconstructie: `sdo:actor` van een gebeurtenis verwijst naar de vermelding. Een tijdlijn bouw je dus in twee stappen: eerst van reconstructie naar vermeldingen, dan van vermeldingen naar gebeurtenissen.

## Vind gebeurtenissen bij een persoon

Welke gebeurtenissen zijn er bekend uit het oorlogsleven van een persoon en wat is daarvoor de bron? Als voorbeeld nemen we de bekende verzetsvrouw Hannie Schaft.

We nemen de ARK identifier van Hannie Schaft als uitgangspunt: `https://n2t.net/ark:/59857/p48968c01-9f60-492d-8712-58d3b8c2b388`

### De query

<SparqlEditor
  query={`PREFIX prov: <http://www.w3.org/ns/prov#>
PREFIX sdo: <https://schema.org/>
SELECT ?datum ?gebeurtenis ?type ?id WHERE {
  <https://n2t.net/ark:/59857/p48968c01-9f60-492d-8712-58d3b8c2b388>
      prov:wasDerivedFrom ?vermelding .
  ?id sdo:actor ?vermelding .
  OPTIONAL { ?id sdo:startDate ?datum }
  OPTIONAL { ?id sdo:name ?gebeurtenis }
  OPTIONAL { ?id sdo:additionalType ?type }
}
ORDER BY ?datum`}
/>

### Wat krijg je terug

Voor Hannie Schaft vinden we 14 vermeldingen van gebeurtenissen, maar deze vermeldingen komen uit verschillende bronnen en hebben uiteindelijk betrekking op een kleiner aantal gebeurtenissen. Eén van deze gebeurtenissen is haar arrestatie op **21 maart 1945**. Type en datum zullen bij meerdere vermeldingen van deze gebeurtenis hetzelfde zijn. 

:::tip[TIP]

De kolom `type` verwijst naar het type persoonlijke gebeurtenis. Deze typen zijn vastgelegd in het [applicatieprofiel](/schema#gebeurtenistypen).

:::

### Variaties

- Niet elke gebeurtenis heeft een `sdo:startDate`; laat de `OPTIONAL` weg om alleen gedateerde gebeurtenissen te tonen.
- Voeg `?id sdo:location ?locatie` toe (eveneens `OPTIONAL`) voor de plaats van de gebeurtenis. 
- Voor een volledig overzicht van alle properties van persoonlijke gebeurtenissen zie [3.3 Gebeurtenissen](/schema#EventShape) in het applicatieprofiel.

## Verzamel alle afbeeldingen en archiefscans

Veel bronnen zijn gekoppeld afbeeldingen, veelal gaat het om scans uit archieven, maar ook portretfoto's zijn te vinden. 

<SparqlEditor
  query={`PREFIX prov: <http://www.w3.org/ns/prov#>
PREFIX sdo: <https://schema.org/>
SELECT * WHERE {
  <https://n2t.net/ark:/59857/pa7cc9745-384c-4939-b46f-12f8fe183062>
      prov:wasDerivedFrom ?vermelding .
  ?vermelding prov:hadPrimarySource ?bron .
  ?bron sdo:holdingArchive ?provider .
  ?bron sdo:associatedMedia ?image .
  ?image sdo:thumbnailUrl ?imageUrl
  OPTIONAL { ?vermelding sdo:hasOccupation ?beroep }
}`}
