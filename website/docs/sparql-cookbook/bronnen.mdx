# Amsterdam in de hongerwinter

## De query

<SparqlEditor
  query={`PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
PREFIX sdo: <https://schema.org/>

SELECT DISTINCT * WHERE {
  ?object a ?type ;
  # about en contentLocation zijn WO2 Thesaurus ID's
  sdo:about <https://data.niod.nl/WO2_Thesaurus/2860> ;
  sdo:contentLocation <https://data.niod.nl/WO2_Thesaurus/locations/9577> ;
  sdo:name ?name ;
  sdo:thumbnailUrl ?thumbnailUrl.

  # ?type matcht matcht ook alle subclasses van sdo:CreativeWork
  ?type rdfs:subClassOf* sdo:CreativeWork .
}

`}
/>

## Wat krijg je terug

Deze query geeft alle objecten: 
- met als onderwerp de Hongerwinter.
- met als onderwerpslocatie Amsterdam.
- van het type `sdo:CreativeWork` of één van haar subclasses.
- waarbij een afbeelding beschikbaar is.
