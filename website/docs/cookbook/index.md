# Cookbook

Taakgerichte recepten voor het werken met de data van Oorlogsbronnen. Elk recept lost één concrete vraag op, met een direct uitvoerbare query en een toelichting op het datamodel erachter.

Als rode draad gebruiken we verzetsstrijder [Hannie Schaft](https://n2t.net/ark:/59857/p48968c01-9f60-492d-8712-58d3b8c2b388) — vervang haar IRI door een andere persoon om hetzelfde recept op jouw onderzoek toe te passen.

- [Bouw een tijdlijn van iemands oorlogsgebeurtenissen](tijdlijn.mdx)
- [Vind alle bronnen bij een persoon](bronnen-bij-persoon.mdx)
- [Van zoekterm naar thesaurusconcept — en terug naar personen](thesaurus.mdx)

De queries draaien op het [SPARQL-endpoint](../services/sparql); het datamodel is beschreven in het [application profile](/schema).
